# FIND IT – 분실물 찾기 커뮤니티

> 잃어버린 물건, 함께 찾아요!

물건을 잃어버린 사람과 주운 사람을 연결하고, **소유자 인증**으로 진짜 주인에게 안전하게 돌려주는 분실물 찾기 웹사이트입니다.

## 바로 보기

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 됩니다.

## 주요 기능

- 분실물 / 습득물 등록 (사진 업로드·미리보기, 필수 항목 검사, 전화번호 노출 차단)
- 검색: 물건 이름·카테고리·장소·날짜·분실/습득 구분 동시 적용, 최신순/오래된 순 정렬
- 게시글 상세, 작성자 확인, 신고(사유 선택)
- 소유자 인증: 비공개 질문 → 자동 1차 확인 → 등록자 최종 승인 → 연락처 공개
- 3회 연속 실패 시 10분 잠금, 작성자만 수정·삭제·승인 가능
- 마이페이지: 내 게시글, 보낸/받은 인증 요청, 반환 완료 목록, 회원 탈퇴
- 반응형(PC·모바일), 샘플 게시글 12개

## ⚠ 시연용 버전 안내

데이터는 브라우저 **localStorage**에만 저장됩니다. 다른 기기·사용자와 공유되지 않으며, 비공개 인증 정보와 답변 비교도 브라우저 안에서 처리되므로 **실제 보안 인증이 아닙니다.** 실서비스로 만들 때는 Supabase 같은 백엔드에서 비공개 정보를 별도 테이블에 두고, 서버 측에서 답변 비교·권한 검사를 해야 합니다.
